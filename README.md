# MathBot — Pre cálculo | GitHub Pages

## Archivos
- `index.html`: página interactiva.
- `fondo_matematicas.png`: fondo matemático.
- `logo_umg.webp`: escudo de la Universidad Mariano Gálvez de Guatemala.

## Publicar
1. Sube los tres archivos a la raíz del repositorio GitHub.
2. Ve a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y carpeta `/(root)`; pulsa **Save**.
5. Copia la URL pública que aparece cuando termine la publicación.

## Funciones incluidas
Diez ejemplos, entrada de ejercicios nuevos, ecuaciones, factorización, derivadas, integrales, límites cuando x tiende a cero, simplificación, gráficas, análisis orientativo de dominio, apoyo visual para rango, composición de funciones, guía para máximos/mínimos y práctica con retroalimentación.

El sitio usa Nerdamer, Math.js y Plotly desde CDN, por lo que necesita Internet. El análisis de dominio/rango y las explicaciones de aplicaciones son orientativos; prueba y verifica las respuestas antes de entregar. Completa el segundo integrante y comprueba las funciones en el navegador.
